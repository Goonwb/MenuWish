# MenuWish v0.1.4

- 新增 Markdown、Numbers、Pages 和 Keynote 文件创建，使用内置原生模板，无需启动对应应用。
- 提供平铺、合并、分类三种菜单布局，空类目自动隐藏。
- 支持功能排序与类目拖动，拖动时自动折叠，结束后恢复展开。
- 支持检查 GitHub Releases 更新，并在应用内查看发布日志。
- 提供仅菜单栏、仅 Dock、菜单栏与 Dock 三种应用入口。
- 优化快捷功能设置布局，统一 Finder 与菜单预览的单色图标。
- 完善 DMG 拖拽安装流程，精简安装说明。

---

## English

- Added Markdown, Numbers, Pages, and Keynote file creation. iWork files use bundled native templates without launching the corresponding apps.
- Added Flat, Combined, and Categories menu layouts, with empty categories hidden automatically.
- Added action ordering and category dragging. Categories collapse during dragging and expand afterward.
- Added GitHub Releases update checks and in-app release notes.
- Added menu bar only, Dock only, and combined app access options.
- Refined action settings and unified monochrome icons in Finder and menu previews.
- Improved drag-to-Applications DMG installation and simplified the instructions.
