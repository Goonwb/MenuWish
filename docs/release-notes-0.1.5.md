# MenuWish v0.1.5

- 新增 Word、Excel 和 PowerPoint 文件创建，支持 `.docx`、`.xlsx`、`.pptx` 格式，可由 Microsoft Office 或 WPS 打开。
- 使用内置空白模板，无需安装或启动办公软件；分别创建一页空白文档、一个空白工作表和一张 16:9 空白幻灯片，重名自动编号。
- 新增文件功能支持独立开关、排序及三种菜单布局，图标统一采用 Hugeicons Stroke Rounded。
- 修复快捷功能设置与排序弹窗中的图标缺失问题。
- 更新中英文使用说明及四张界面截图。

---

- Added Word, Excel, and PowerPoint file creation in `.docx`, `.xlsx`, and `.pptx` formats, compatible with Microsoft Office and WPS.
- Bundled blank templates create one blank document page, one empty worksheet, or one blank 16:9 slide without installing or launching an office app. Duplicate names are numbered automatically.
- New file actions support individual switches, ordering, and all three menu layouts, with consistent Hugeicons Stroke Rounded icons.
- Fixed missing icons in action settings and the ordering dialog.
- Updated the Chinese and English documentation and all four interface screenshots.
